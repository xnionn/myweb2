Страница выполнена на английском в теме книжного клуба Bookbound. Мелкие поясняющие подписи и служебный футер удалены. Все пять компонентов используют один файл task2.css.

1. Группа ссылок переносится; автоматический начальный отступ прижимает действия к правому краю.
2. Flexbox растягивает карточки до одинаковой высоты внутри ряда. Каждая карточка — вертикальный flex-контейнер, а margin-top: auto у кнопки забирает свободное место над ней. Одинаковые подписи и общая типографика сохраняют одинаковую высоту кнопок.
3. Три равные flex-области удерживают номера страниц по центру всей панели. На узком экране области переносятся, счётчик остаётся справа. Элементы пагинации являются статическим примером компонента.
4. Аватар не сжимается, текст занимает отдельную гибкую колонку. Перенос длинных слов не позволяет тексту выйти за её границы.
5. Тарифы растягиваются по содержимому, а вертикальные внешние отступы уменьшают соседние планы. У рекомендованного плана этих отступов нет, поэтому он выше остальных планов в том же ряду.

Проверены ширины 320, 375, 390, 500, 768, 1024, 1440 и 1920 пикселей, обычный и удлинённый текст, отсутствие горизонтальной прокрутки, выравнивание кнопок, фокус с клавиатуры и контраст текста. Высота кнопок карточек составила 42,78125 CSS px во всех этих проверках; это результат текста и отступов, а не заданная в CSS высота.

- В сетке Grid автоматически подбирает количество столбцов, а Flexbox располагает содержимое карточки.
- В списке Grid создаёт одну колонку, а Flexbox ставит изображение, текст и дату в ряд.
- В журнале Grid растягивает ведущую статью на два столбца и две строки, а Flexbox управляет её содержимым.

Во всех трёх режимах используются одни и те же двенадцать статей. Во время съёмки менялся только класс контейнера.

Для каждого режима также сохранены `full-*.png` со всеми 12 статьями, `mobile-*.png` с верхом страницы и `mobile-full-*.png` со всей мобильной страницей. Проверены восемь ширин от 320 до 1920 px, длинные заголовки, слова без пробелов и переключение с клавиатуры.

Скриншоты относятся к исходникам в репозитории Web2. Задания 2 и 3 также подготовлены для учебной копии `myweb2`, где стили подключаются из папки `css`.
